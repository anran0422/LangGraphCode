你现在这个练习最值得沉淀的一句话就是：

Send = 把主 State 中的一批数据拆成多个“自定义小 State”，
分别发送给目标节点并行处理；多个处理结果再通过 Reducer 合并回主 State。

整个过程可以直接理解成：
```
State
scores = [89, 38, 68, 55, 90]
              │
              ▼
             Send
              │
     ┌────────┼────────┐
     ↓        ↓        ↓
 score=89  score=38  score=68  ...
     ↓        ↓        ↓
 node_judge node_judge node_judge
     │        │        │
     └────────┼────────┘
              ↓
          Reducer
              ↓
result = ["及格", "不及格", "及格", ...]

这其实就是一个非常标准的 Map → Reduce。
```

所以你直接沉淀一句：

普通条件边通常需要返回路由结果，再由 path_map 映射到节点；
而 Send 自身已经携带目标节点，因此它本身就具有指定路由的能力。

再精简一点就是：
Send = 指定目标节点 + 携带发送状态。
```angular17html
Send(节点名称, 参数字典)
Send("node_judge", {"score": 89})
```
