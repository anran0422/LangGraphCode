你可以直接记到 LangGraph 笔记里：
```
1. Checkpoint 保存的是某个时间点的 State 和图的执行位置。
2. get_state_history() 可以获取一个 thread 的历史 Checkpoint。
3. 时间旅行不是修改过去的 Checkpoint，而是选择过去的 Checkpoint 作为新的执行起点。
4. 重新执行时使用当前的节点逻辑，而不是恢复当时的 Python 代码。
5. 因此，时间旅行可以让同一个历史 State 在不同的当前逻辑下重新执行，从而产生新的结果。
```
你这次这个练习，实际上已经把 
Checkpoint → History → 选择历史 State 
→ next → 重新执行 → 新 State 这一整条链路走通了。
